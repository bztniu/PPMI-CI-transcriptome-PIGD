# Peripheral blood mitochondrial complex I transcriptomic axis in Parkinson's disease

This repository contains the R analysis code used for the manuscript on a peripheral-blood mitochondrial complex I (CI) transcriptomic axis and late PIGD progression in Parkinson's disease.

## Scope

The `R/` folder contains scripts for the analyses and figures retained in the current manuscript:

- CI-gene PCA and structure assessment
- genome-wide differential expression
- KEGG-GSEA / GO-related figure generation
- PD-risk gene screening
- NNLS immune-cell deconvolution and immune sensitivity analyses
- longitudinal PIGD linear mixed-effects models
- latent-class trajectory (LCMM) modelling of PIGD trajectories (supplementary figure)
- DAT-SPECT and focused fluid-biomarker context analyses
- Figure 1, Figure 2, Figure 3, and supplementary figure generation

Exploratory machine-learning prediction scripts were not included in this release folder because those analyses were removed from the main manuscript narrative.

## Important Note on Input Files

This release is a manuscript-code package, not a fully containerized one-click pipeline from raw PPMI downloads. Several scripts use derived analysis tables created during local preprocessing, for example cleaned sample annotations, PC1 scores, DESeq2 outputs, immune deconvolution summaries, longitudinal LMM summaries, DAT-SPECT summaries, and focused biomarker tables.

In other words:

- Some scripts read original or near-original PPMI files.
- Some scripts read intermediate tables generated by earlier scripts.
- Some figure scripts read curated result tables under the manuscript `04_tables/` folder.

This structure is intentional because PPMI individual-level data are controlled access and cannot be redistributed. Before rerunning the pipeline, users should either reproduce the same intermediate tables from their authorized PPMI download or update paths and object names to match their own preprocessing workflow.

For a script-by-script map of input files, source category, and outputs, see `CODE_INPUTS.md`.

## Data Availability

PPMI individual-level clinical, imaging, biomarker, and RNA-seq data are controlled-access data and are not redistributed here.

The scripts assume the same local file organization used during analysis. Before running, update hard-coded paths such as:

```r
ROOT <- "E:/PPMI帕金森数据库专用"
OUT_DIR <- "E:/PPMI帕金森数据库专用/结果/新结果/实验/movementdisorders/new/revision_v2"
```

to match your own data location.

## Suggested Script Review / Run Order

1. Install package dependencies:

```r
source("R/00_install_pkgs.R")
```

2. Prepare core analysis tables:

```r
source("R/01_prep_data.R")
```

3. Run CI-axis structure and molecular analyses:

```r
source("R/02_structure_assessment.R")
source("R/03_pca_eigencor.R")
source("R/04_run_gsea_lowCI.R")
source("R/05_screen_pd_risk_genes.R")
source("R/06_run_ssgsea.R")
```

4. Run longitudinal, DAT, biomarker, and immune sensitivity analyses:

```r
source("R/07_kmeans_immune_check.R")
source("R/08_lmm_sweep.R")
source("R/09_lmm_sweep_full.R")
source("R/10_lmm_sweep_forest.R")
source("R/11_lmm_sweep_full_forest.R")
source("R/12_dat_subregion_sweep.R")
source("R/13_biomarker_sweep.R")
source("R/14_biomarker_volcano.R")
source("R/15_cell_fraction_sensitivity.R")
source("R/16_pigd_lcmm_trajectory.R")
```

5. Generate figures:

```r
source("R/17_make_figure1.R")
source("R/18_make_figure2.R")
source("R/19_make_figure3.R")
source("R/20_make_classic_biomarker_figure.R")
source("R/21_make_figS1_structure.R")
```

Notes on the two most recently added scripts:

- `R/15_cell_fraction_sensitivity.R` reproduces the blood-cell-composition sensitivity analysis for the year-5 PIGD interaction (Supplementary Table S15).
- `R/16_pigd_lcmm_trajectory.R` runs the latent-class mixed model on PIGD trajectories and generates the supplementary LCMM trajectory figure (Fig. S); it requires the `lcmm` package and is expected to run from the repository root so that `04_tables/` and `02_figures/` resolve correctly.

## Notes

- The current Figure 3 focuses on the year-5 PIGD LMM signal, clinical specificity, DAT-SPECT context, and established fluid biomarkers.
- Machine-learning and LCLMM exploratory analyses were intentionally excluded from this GitHub release folder because they are no longer part of the manuscript's main analysis set.
- Random seeds are set within scripts where stochastic procedures are used.
- Some scripts require Bioconductor annotation packages and PPMI-specific derived input files created during preprocessing.
